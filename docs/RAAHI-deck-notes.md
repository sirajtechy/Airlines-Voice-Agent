# Speaker notes — RAAHI demo deck

Companion to [RAAHI-loom-deck.pptx](RAAHI-loom-deck.pptx). Generated by
`scripts/build-deck.py` — edit the script, not this file.

Notes live here rather than inside the .pptx because python-pptx's notes-slide
output is rejected by PowerPoint and by macOS's renderer, which made the deck
appear corrupted. Keep this open on a second screen while recording.
