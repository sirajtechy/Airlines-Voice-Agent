2 · The run — say exactly this

0:00–0:25 · Opener (face to camera)

YOU SAY"During a flight disruption, the answer a passenger needs is two sentences of prose buried on the airline's travel-updates page. It changes without warning, and nobody can read it standing in a terminal. This is RAAHI — a voice agent that reads that page at the moment you ask. Built today on ElevenLabs and context.dev."

0:25–1:45 · Live demo — the segment that scores

ASK RAAHI"My booking reference is K seven X two M nine — should I leave for the airport?"
WHILE IT ANSWERS, SAY OVER IT"That answer is not in any database. It just read the Emirates travel-updates page live through context.dev — and the restriction it found is on where she's coming from, not where she's going."
→ Switch to Tab 2. Point at the exact sentence: "…even those arriving by indirect routings." Then back to Tab 1.
ASK (PROVES NOTHING IS HARDCODED)"Now try P three L eight Q K."  → same destination, opposite verdict — say so.
BARGE-IN — CUT IT OFF MID-SENTENCE"— sorry, where is E K three-oh-five right now?"  → live ADS-B position via the native MCP server. Name it: "that's a second integration path — a native MCP server, live transponder data."
ASK"Has that advisory changed today?"  → Monitor answer, minutes-ago precision.

1:45–2:05 · Why live data (finish the sentence)

YOU SAY"Our project would fundamentally break without live web data because a restriction lifted yesterday and one extended this morning produce opposite advice — and neither has an API, only a page. And a context.dev Monitor watches that page and pushes signed diffs to us, so RAAHI can tell you it changed while you were talking to it."

2:05–2:25 · What it does on its own

YOU SAY"It chains tools unprompted — restriction, then rebooking, then support. It checks both ends of a journey, because restrictions key off where you've been. It refuses to answer route questions from memory, and every response carries a freshness label that binds its phrasing. Twelve webhook tools plus a native MCP server, barge-in, and it switches to Arabic or Hindi mid-call."

2:25–2:40 · Novel

YOU SAY"The knowledge source is the airline's own unstructured advisory prose, parsed live — checking the leg of the journey nobody checks. Not a booking bot, not an FAQ."

2:40–2:55 · Hardest problem

YOU SAY"Turning that prose into a decision. Three things broke the naive version: the restriction keys off origin, not destination. The qualifier that changes the answer sits in the next sentence. And 'effective 6 June, until further notice' contains a date that is not an end date. Fixed with two-sided matching, sentence windows and open-ended detection — pinned by fifty tests against verbatim page text."
